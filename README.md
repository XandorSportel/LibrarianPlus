### 🧩 What is LibrarianPlus?

**LibrarianPlus** is a Minecraft plugin that makes it easier to find the enchantments you want from librarian villagers. \
When you place a lectern:
* ✅ A sound plays if the librarian offers an enchantment you selected.
* ❌ Another sound plays if it doesn’t.

This saves time by letting you know right away — no need to open the trade screen.

---

### 📥 Installation
1. Download the latest `.jar` file from the [Releases](https://github.com/milanh-dev/LibrarianPlus/releases) tab.
2. Place it in your server's `/plugins` folder.
3. Restart or reload your server.

---

### ⚙️ How to Use
1. Use command `/librarianmenu` to select enchantments you want.
2. Place a lectern near an unemployed villager.
3. Listen for the sounds to know if the trade matches your selection.

---
